# GitHub 商业化雷达 · 第 1 期

**主题：个人能拿下、且能收钱的方向**

数据截至 2026-11-16，样本 1456 个 GitHub 热门仓库，经许可证、活跃度、体量、合规四道筛子后剩 745 个。本期人工精选 13 个。

---

## 先看结论

如果只想选一条路，按下面顺序试：

1. **AI 视频 / Agent 技能工作流** —— 热度最集中，客户是内容团队，付费意愿明确，个人一两周能做出可用版本。
2. **成熟系统的私有化交付** —— 不需要重新验证产品，卖部署、改造和运维，成交靠信任不靠流量。
3. **垂直行业系统二次包装** —— 客单价最高，但需要行业理解，适合有相关资源的人。

不建议做：通用 AI 套壳、泛效率工具、需要大规模投流的 consumer 产品。

## 榜单 A：AI Agent 技能与视频工作流

这一组是本期最强信号。10 月后新出现的一批仓库，全部围绕"把 Agent 变成能干活的工具"，且都带 MCP / Skill 生态。

### 1. ffmpeg-skill —— 让 Agent 真正会剪视频

- **仓库**：[kajisho5/ffmpeg-skill](https://github.com/kajisho5/ffmpeg-skill) · 5170★ · 439 fork · MIT · Python
- **是什么**：把 42 个 FFmpeg 能力封装成机器可读契约 + MCP Server，Claude Code / Cursor / Codex 可直接调用。剪辑、字幕、转码、抽帧全在本地跑。
- **可复用**：MCP 工具定义、参数契约、本地处理链路。
- **切入点**：做"短视频批量处理"的垂直封装——比如固定做口播视频去停顿、加字幕、切成 3 个竖版尺寸，一键出片。技术难度低，客户看得懂效果。
- **变现**：¥99–299 一次性买断的本地工具；或按条计费的处理服务。
- **风险**：纯本地工具容易被白嫖，需要做易用性和模板壁垒。
- **信号**：上线 2 个月 5170★，439 fork，说明真有人在接。

### 2. openfilm —— AI 视频 Agent + 可改编辑器

- **仓库**：[openfilm/openfilm](https://github.com/openfilm/openfilm) · 5882★ · 567 fork · MIT · TypeScript
- **是什么**：把任意 coding agent 变成视频 agent，生成后用编辑器手动改任何细节。
- **可复用**：生成 + 可编辑的闭环，这是目前 AI 视频产品最缺的一环。
- **切入点**：给电商团队做"商品短视频批量生成"——上传商品图，套模板，出 5 条不同风格。卖的是模板和行业适配，不是模型。
- **变现**：按条收费（¥5–20/条）或月付；企业版做私有部署。
- **风险**：依赖模型成本波动，必须做模板化降低调用次数。

### 3. rea-video —— 逐镜头逆向任意视频

- **仓库**：[JuneYaooo/rea-video](https://github.com/JuneYaooo/rea-video) · 7321★ · 1078 fork · Apache-2.0 · Python
- **是什么**：把一个视频拆成逐个镜头，判断是实拍、AI 生成还是代码生成，输出可复刻的 VIDEO.md。
- **可复用**：镜头拆解、AIGC 判定、结构化输出格式。
- **切入点**：做"爆款视频拆解报告"——给投放团队拆竞品素材，输出分镜、节奏、文案结构、复刻提示词。这是明确的信息差生意。
- **变现**：单条拆解 ¥50–200，或包月 ¥999 起。
- **风险**：涉及平台内容抓取，注意不要提供下载和二次分发功能。

### 4. AIHOT —— 自动找热点、自动写日报的站点框架

- **仓库**：[KKKKhazix/AIHOT](https://github.com/KKKKhazix/AIHOT) · 10462★ · 2436 fork · MIT · TypeScript
- **是什么**：自带信源抓取、LLM 精选、日报生成的完整网站框架，Docker Compose 一键起。
- **可复用**：抓取 + 去重 + 精选 + 生成 + 发布的完整流水线。
- **切入点**：换成某个垂直行业信源（如医疗器械招标、跨境物流政策），做成行业情报站，卖订阅。
- **变现**：行业情报订阅 ¥99–499/年；或给企业做内部情报系统。
- **风险**：内容合规和版权，必须改写不能原文搬运；同质化高，壁垒只在信源质量。

## 榜单 B：成熟系统的私有化交付

这组项目都跑了很多年，产品被验证过，你的价值是**交付能力**而不是产品创意。

### 5. kanboard —— 看板项目管理

- **仓库**：[kanboard/kanboard](https://github.com/kanboard/kanboard) · 9956★ · 2028 fork · MIT · PHP
- 2014 年至今仍在维护。轻量、单机可跑、中文可用。
- **切入点**：给 10–50 人的小公司做私有看板，配好备份、HTTPS、企业微信通知。
- **变现**：部署 ¥2000–5000/次，年运维 ¥1000–3000。

### 6. wallabag —— 稍后读 / 知识归档

- **仓库**：[wallabag/wallabag](https://github.com/wallabag/wallabag) · 13061★ · 913 fork · MIT · PHP
- **切入点**：给研究型团队、律所、咨询公司做"资料归档 + 全文检索"的内部知识库。
- **变现**：部署 + 数据迁移 ¥5000 起；这类客户对数据私有化极敏感，价格不敏感。

### 7. Krayin CRM —— Laravel 系 CRM

- **仓库**：[krayin/laravel-crm](https://github.com/krayin/laravel-crm) · 24144★ · 1682 fork · MIT · PHP
- 带 多租户 SaaS 相关标签，改造空间大。
- **切入点**：给传统行业销售团队做定制 CRM，砍掉用不上的模块，只留线索、跟进、报价。
- **变现**：定制开发 ¥1–5 万/项目，按模块报价。

### 8. ntfy —— 自托管推送服务

- **仓库**：[binwiederhier/ntfy](https://github.com/binwiederhier/ntfy) · 35497★ · 1709 fork · Apache-2.0 · Go
- 一个 PUT/POST 就能推送到手机和桌面，极轻。
- **切入点**：作为其他系统的"通知底座"打包进交付方案；也可做监控告警托管服务。
- **变现**：作为附加模块收费，或按消息量做托管套餐。

## 榜单 C：垂直行业系统

客单价高，但需要行业资源。没有客户资源不要先做。

### 9. Aureus ERP —— 开源 ERP

- **仓库**：[aureuserp/aureuserp](https://github.com/aureuserp/aureuserp) · 12203★ · 624 fork · MIT · PHP
- 覆盖财务、库存、HRM、发票、维护，基于 Filament。
- **切入点**：外贸、批发类小企业的轻量 ERP 落地，重点是**把他们的 Excel 迁进来**。迁移服务才是利润点。

### 10. Bagisto —— 电商 / 多商户平台

- **仓库**：[bagisto/bagisto](https://github.com/bagisto/bagisto) · 28363★ · 3386 fork · MIT · PHP
- 支持 10M+ SKU，B2B 和多商户场景成熟。
- **切入点**：做垂直品类商城（如汽配、工业耗材），卖"建站 + 品类数据导入 + 支付对接"。
- **注意**：电商涉及支付、备案、售后，比工具类项目重得多。

### 11. Filament —— Laravel 后台框架

- **仓库**：[filamentphp/filament](https://github.com/filamentphp/filament) · 32483★ · 4240 fork · MIT · PHP
- 上面两个项目的底座。会它能接几乎所有 PHP 后台定制单。
- **切入点**：不直接卖，作为接单能力。这是接单型开发者最值得投入的一项技能。

## 榜单 D：个人桌面工具（小而快）

### 12. Clipy —— macOS 剪贴板历史

- **仓库**：[Clipy/Clipy](https://github.com/Clipy/Clipy) · 8972★ · 843 fork · MIT · Swift
- **切入点**：加行业专用能力（如设计素材收藏、代码片段管理、常用回复库），做成垂直剪贴板工具。
- **变现**：¥30–68 买断，或 Setapp 类订阅平台上架。

### 13. Plexo —— 多连接并行下载

- **仓库**：[anmolkapil/plexo](https://github.com/anmolkapil/plexo) · 5683★ · 415 fork · MIT · TypeScript
- 2026-09 新建，两个月 5683★，跨平台桌面。
- **切入点**：面向素材/视频团队的批量下载与整理工具，加素材去重、命名规范、云盘同步。
- **变现**：买断 + 团队授权。

## 筛选口径
