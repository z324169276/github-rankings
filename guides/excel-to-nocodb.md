# 团队共用 Excel 老是冲突，有没有更省事的办法？

一个表格放在共享盘上，两个人同时打开，第二个人只能只读。想改？另存为一份副本，文件名加上「最终版」「最终版2」「最终版-张总改」。

三个月后，没人知道哪份是对的。

## 问题不在 Excel，在「共享文件」这个模式

Excel 是为单机设计的。放在共享盘上，它依然是「一个文件」，不是「一个系统」。

真正需要的是三件事：

- 多个人同时改，不互相覆盖
- 每个人只看到自己该看的行和列
- 改了什么、谁改的，有记录

这三件事 Excel 都能勉强做，但每一样都要额外折腾：共享工作簿会丢格式，保护工作表挡不住复制，修订记录超过一定时间就没了。

## 做法：把表格变成一个内部数据库

NocoDB 的思路是：界面还是表格的样子，底层是数据库。用起来接近 Excel，但多人协作、权限、筛选视图都是原生的。

一台 2 核 4G 的服务器：

```bash
docker run -d --name nocodb \
  -p 8080:8080 \
  -v ./nocodb:/usr/app/data \
  --restart unless-stopped \
  nocodb/nocodb:latest
```

打开 `http://服务器IP:8080`，创建管理员账号，然后新建项目、新建表。

### 迁移现有 Excel 的正确顺序

不要一上来就把整张表导进去。顺序应该是：

1. **先拆字段**。把「备注」里混着的东西拆成独立列，比如「客户等级」「跟进状态」。字段不拆，后面做什么筛选都没用。
2. **再统一格式**。日期统一成一种格式，金额去掉货币符号，手机号去掉空格。
3. **然后导入**。NocoDB 支持直接导入 xlsx，但脏数据导入后改起来更麻烦。
4. **最后建视图**。给每个人一个视图：销售只看自己的客户，财务只看金额和开票状态。

### 权限怎么设

NocoDB 的权限粒度到「表」这一级，够用但有边界：

- 老板：全部表可编辑
- 部门负责人：本部门表可编辑，其他只读
- 普通员工：只能编辑分配给自己的行（需要配合筛选视图）

如果要求「同一条记录，销售能看金额不能看成本」，这种字段级权限，NocoDB 做不了，得换方案。

## 三个真实的坑

**数据量**。五千行以内很顺，超过五万行，筛选和排序会明显变慢。它不是为大数据量设计的。

**公式**。只支持基础的公式和关联，不支持 Excel 里的复杂函数和宏。原来靠公式算的东西，要改成字段关联或者手算。

**旧习惯**。上线后一定有人继续用 Excel 导出一份自己改。唯一的解法是收掉共享盘上那份旧文件的写权限，否则两套数据很快就对不上。

## 什么情况别这么做

**只有一个人维护表格**：继续用 Excel，加个自动备份就够了，不需要系统。

**表格里有大量公式和图表**：迁移成本远高于收益，Excel 在计算和图表上仍然更强。

**需要和 ERP、财务系统打通**：这是集成项目，不是换个工具能解决的。

## 什么时候该找人

如果你的表格已经出现「不知道哪份是对的」、或者有人因为看不到数据反复来问，说明该动手了。

自己装一个 NocoDB 不难，难的是字段怎么拆、权限怎么分、历史数据怎么清。这部分通常占整个工作量的一大半。

> 我这边做的小团队私有系统交付：¥3000–12000，含部署、字段建模、历史 Excel 导入和一次培训，验收标准是「你自己录入十条真实数据并成功导出」。
